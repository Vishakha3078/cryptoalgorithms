## Overview

An implementation-based project exploring fundamental cryptographic
algorithms and techniques used for encryption, hashing, and secure
communication.

## Implemented Algorithms

- Hashing
- ElGamal
- Diffie-Hellman Key Exchange
- Elliptic Curve Cryptography (ECC)

## Features

- Implementation of cryptographic algorithms
- Encryption and decryption operations where applicable
- Key generation and key exchange concepts
- Exploration of cryptographic techniques for data protection

## Technologies
- C++
